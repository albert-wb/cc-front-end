# Desenvolvimento Front-End Para Web

Repositório da disciplina de Desenvolvimento Front-End Para Web.

## Sobre o Projeto
Ao longo das aulas, construímos do zero o projeto prático **IngressosFácil**, aplicando fundamentos da Web, marcação HTML5 semântica, estilização avançada com CSS3, manipulação do DOM com JavaScript, multimídia, gráficos e layouts responsivos com Flexbox.
