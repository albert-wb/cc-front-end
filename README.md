# Desenvolvimento Front-End Para Web

Repositório da disciplina de **Desenvolvimento Front-End Para Web**.

## 🚀 Sobre o Projeto
Este repositório documenta e implementa passo a passo o conteúdo prático das aulas, consolidado no projeto **IngressosFácil** e nos exemplos práticos de laboratório.

## 📚 Roteiro das Aulas Implementadas

1. **Aula 01** - Apresentação da Disciplina e Fundamentos da Web (Arquitetura Cliente-Servidor, DNS, HTTP/HTTPS).
2. **Aula 02** - Estrutura de Projetos Front-End e sintaxe básica do HTML5.
3. **Aula 03** - Elementos fundamentais do HTML: Títulos, parágrafos, listas (ul/ol), tabelas semânticas (Quadro de Medalhas Paris 2024), links seguros e imagens.
4. **Aula 04** - HTML Semântico e estruturação inicial do projeto IngressosFácil (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
5. **Aulas 05 e 06** - Formulários HTML, validação nativa (pattern de CPF, minlength, required), manipulação do DOM (`addEventListener('submit')`) e versionamento com Git.
6. **Aula 07** - Fundamentos do CSS, seletores universais, de tag, classe, ID e cascata/especificidade.
7. **Aula 08** - Estilização completa do IngressosFácil passo a passo (Reset, body, tipografia rem, links LVHA, listas, tabelas com zebra striping, cards com sombra, cabeçalho e rodapé).
8. **Aula 09** - Recursos Multimídia (Vídeo e Áudio com player customizado, mapa incorporado via `<iframe>`) e Gráficos (Selo VIP em Canvas 2D e gráfico vetorial SVG).
9. **Aula 10** - Layouts Responsivos com Flexbox, pseudo-classes (`:focus`, `:not`), pseudo-elementos (`::before`, `::after`), cabeçalho flexível, grade dinâmica de cards e rodapé fixado via coluna flex.
10. **Aula 11** - CSS Grid Layout: estruturação bidimensional com grid-template-areas, vitrine de cards com auto-fit/minmax, controle de trilhas e responsividade.
11. **Aula 12** - Bootstrap 5: framework de estilos, sistema de 12 colunas, componentes pré-estilizados (navbar responsiva, cards com grid, list-group, forms com input-group) e classes utilitárias.
